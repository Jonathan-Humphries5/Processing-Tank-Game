# Processing-Tank-Game
"Don't Crash" - A 2D game made using processing(Java)

<img width="906" height="838" alt="Animation-ezgif com-optimize" src="https://github.com/user-attachments/assets/252273ec-c411-4679-8b20-c727cc62d1a9" />


Features: enemy tanks that shoot back, landmines, a player gun with ammo and reloading, rising levels, a persistent high score.

How to run: install Processing, open final_project.pde, press the play button.

Controls: arrow keys move, left-click shoots, R reloads
1 - Pause
0 - Play
2 - Reset

Future Updates: in the future I would like to add smarter enemy movement, better graphics and sound for explosions, firing projectiles and tank movements
